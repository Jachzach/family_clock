Set up OwnTracks

Install OwnTracks from the App Store or Play Store first, then tap:

Open OwnTracks with my settings

Afterwards:

  1. iPhone: Settings → OwnTracks → Location → Always, and Settings → General → Background App Refresh → on.
  2. Android: Settings → Apps → OwnTracks → Permissions → Location → Allow all the time, and Battery → Unrestricted.
  3. In OwnTracks, tap the publish / report button once.
